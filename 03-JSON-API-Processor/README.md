# REST API & JSON Data Processor

Python project demonstrating REST API integration and JSON processing.

## Features

* Fetch API Data
* Parse JSON
* Filter Records
* Export CSV
* Export JSON
* Generate Summary

## Run

```bash
python api_data_processor.py
```

## Outputs

* processed_users.csv
* processed_users.json
* api_summary.json

## Use Case

Useful for automation engineers working with APIs and structured data.
