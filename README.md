# 👨‍💻 About This Repository

This repository contains four hands-on Python projects designed to demonstrate practical skills in IT Infrastructure, Automation, API Integration, Log Analysis and Generative AI.

The objective of these projects is to build real-world Python utilities that align with IT Operations, Cloud Engineering, DevOps and AI Engineering roles.

---

# 🚀 Project Architecture

The complete architecture illustrates how different Python utilities process system information, logs, REST APIs and AI conversations to generate meaningful outputs.

---

# 📂 Projects

## 1️⃣ Python IT Admin Assistant CLI

A command-line IT administration toolkit for Windows infrastructure operations.

### Features

* System Information
* Hostname & Local IP
* Ping Diagnostics
* DNS Lookup
* Disk Usage Monitoring
* Running Process Inspection
* IP Configuration

### Technologies

Python • Platform • Socket • Subprocess • Shutil

---

## 2️⃣ Python Log Analyzer

A practical log analysis utility for IT Operations and DevOps teams.

### Features

* Read Log Files
* Error Detection
* Warning Detection
* INFO Analysis
* IP Address Extraction
* Log Statistics
* Automated TXT Report Generation

### Technologies

Python • Regex • Collections • File Handling

---

## 3️⃣ REST API & JSON Data Processor

A Python application that consumes REST APIs and processes JSON data.

### Features

* REST API Integration
* HTTP Response Handling
* Nested JSON Parsing
* Data Filtering
* CSV Export
* JSON Export
* Summary Report Generation

### Technologies

Python • JSON • CSV • urllib

---

## 4️⃣ Python GenAI IT Assistant

A Generative AI command-line assistant designed for IT professionals.

### Features

* Interactive CLI Chatbot
* Multi-turn Conversation
* Secure API Key Handling
* Conversation Reset
* Help Commands
* Error Handling
* IT / Cloud / DevOps Assistant

### Technologies

Python • OpenAI SDK • Generative AI

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Avinashsingh011/Avinash-Python-GenAI-Mini-Projects.git
```

Move into project folder

```bash
cd Avinash-Python-GenAI-Mini-Projects
```

Run any project

```bash
python filename.py
```
