# Python GenAI IT Assistant

A Python command-line Generative AI assistant for IT professionals.

## Features

* Interactive Chatbot
* Multi-turn Conversation
* Help Command
* Clear Conversation
* Secure API Key
* Error Handling

## Installation

```bash
pip install openai
```

## Environment Variable

```powershell
$env:OPENAI_API_KEY="YOUR_API_KEY"
```

## Run

```bash
python ai_chatbot.py
```

## Commands

```text
/help
/clear
/exit
```

## Security

Never upload your API key to GitHub. Use environment variables only.
