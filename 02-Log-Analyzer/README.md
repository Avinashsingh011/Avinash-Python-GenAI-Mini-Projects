# Python Log Analyzer

A Python utility for analyzing infrastructure and application logs.

## Features

* Error Detection
* Warning Detection
* INFO Messages
* IP Address Extraction
* Log Statistics
* Automated TXT Report

## Run

```bash
python log_analyzer.py
```

## Input

```text
sample.log
```

## Output

```text
log_analysis_report.txt
```

## Use Case

Designed for DevOps and IT Operations teams to quickly analyze server logs.
