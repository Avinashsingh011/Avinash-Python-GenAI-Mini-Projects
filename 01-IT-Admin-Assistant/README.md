# Python IT Admin Assistant CLI

A command-line Python utility for daily IT administration tasks.

## Features

* System Information
* Hostname Detection
* Local IP Address
* Ping Utility
* DNS Lookup
* Disk Usage Monitoring
* Running Processes
* IP Configuration

## Run

```bash
python it_admin_assistant.py
```

## Use Case

Useful for System Administrators and IT Support Engineers performing quick infrastructure diagnostics.
